# WalletIQ

**Track, Budget, and Optimize Your Finances with Ease**

WalletIQ is a full-stack web application that helps users manage their personal finances efficiently. It allows tracking income and expenses, managing accounts, setting budgets, performing transfers, and analyzing spending patterns with interactive dashboards and charts.

---

## **Features**

- **User Authentication:** Secure registration and login system using **JWT tokens**.
- **Profile Management:** Users can update their profile information.
- **Expense & Income Tracking:** Add, edit, and delete transactions with detailed categorization.
- **Transfers:** Perform money transfers between accounts easily.
- **Accounts Management:** CRUD operations for multiple accounts.
- **Categories:** Organize transactions by categories for better tracking.
- **Dashboard with Charts & Graphs:** Visualize income, expenses, and transfers with interactive charts.
- **Detailed Analytics:** Track trends, budget adherence, and spending patterns.
- **Search & Filter:** Quickly search transactions and filter by category, account, or date.
- **Responsive & Modern UI:** Clean, user-friendly interface optimized for desktop and mobile.

---

## **Tech Stack**

- **Frontend:** React, Material UI, Recharts
- **Backend:** Python, Django, Django REST Framework (DRF), JWT Authentication
- **Database:** PostgreSQL
- **Tools & Utilities:** Postman, Git, GitHub, VS Code
